# HIEU AUTO DIM PRO MVP09

Status: experimental. Inventor Drawing 2025–2027 iLogic rule for 2D orthographic views only.

The rule attempts overall dimensions and circle/hole locating dimensions. It skips isometric views, refuses sheets with existing general dimensions, and emits diagnostics.

Use only on a backup of a clean drawing. Review all generated dimensions manually. Full feature coverage, overlap prevention, Inventor compilation and runtime acceptance are not yet verified. This is not a production release.

Source: `HIEU_AUTO_DIM_MVP09.iLogicVb`.
